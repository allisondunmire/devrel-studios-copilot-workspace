# Projects

One `.md` file per project. Use `_template.md` as a starting point.

## Naming
- Use kebab-case: `my-project-name.md`
- Keep it short but recognizable

## Workflow
- **Active work** → file lives here
- **On hold / completed** → keep the file, update status at the top
- High-level status across all projects lives in `../context/projects.md`
